日记模板Daily Note Template

一个让「每天写日记」自动发生的插件：
按模板生成、跟着当天的内容更新、自动补齐漏掉的日子，
并维护「年 → 月 → 日」的完整结构。

01

不断档

哪天没打开 Obsidian，下次启动会把缺的日子按顺序补上，日记序列不会断。

02

会生长

待办跟着「今天」的清单走；勾选状态第二天自动还原，做完的紧急任务自动消失。

03

有结构

每年、每月自动生成节点，日记自动挂上所属月份，形成可回溯的时间轴。

打开 Obsidian  →  今天的日记已就位（按模板）  →  开始写
                →  模板里的清单跟着变  →  明天照做

日记模板 · 功能说明02

它解决的三个麻烦

困扰插件的做法
每天手动复制模板新建日记时自动套用你设定好的模板，改一次模板，以后都生效。
某天没开 Obsidian，日记就空了启动、跨天、休眠唤醒时自动检查，把缺的日子按模板补齐。
任务清单每天重建，勾选状态混乱待办自动镜像昨天的清单并还原勾选；任务 / 紧急任务只保留下没做完的。

功能一 · 每天的日记自动就位 不用你点开

时机行为
Obsidian 启动从「最近一篇日记」的第二天补到今天，中间缺几天补几天。
跨零点 / 休眠唤醒每分钟检查日期，变了就补建，且不会切走你正在看的笔记。
今天已经建过不重复创建；你主动删掉今天的日记，当天也不会反复重建。
缺的日子过多只补最近 N 天（默认 31，可改）；历史空档用命令手动补齐。
为什么历史空档要手动？自动补建只向前看，否则每次启动扫全仓库会把删掉的旧日记反复重建。

功能二 · 待办是「活」的 跟着今天变

To-do list · 每日待办

完整镜像今天的清单：今天加一条，明天就有；删一条，明天就没有。勾选状态在新日记里全部还原成未勾选。

Mission · 任务

只带「没打勾」的：新加进来的进入明天；打勾完成的从模板里消失，当天日记不受影响。

Urgent mission · 紧急

与 Mission 完全同一套规则，只是你按紧急与否分开放；两栏互不影响。

改动今天的日记，停手约 0.7 秒模板就同步；设置页能看到来源和明天会带走的清单。

默认模板 整段可以换掉

模板里的写法生成日记时
# To-do list填入 {{todo_list}}：今天清单的完整镜像，勾选全部还原
## Mission填入 {{mission_list}}：只带没打勾的条目
## Urgent mission填入 {{urgent_list}}：规则同上
# Exercise保留标题，{{cursor}} 决定光标停在哪一行

标题名、顺序、其它段落都能改；忘放占位符时也会兜底插到同名标题下。

功能四 · 模板随时可改 两种来源

内置文本

在设置页的大文本框里直接写，输完自动保存；点「预览渲染结果」可先看效果。

笔记文件

用一个 Markdown 笔记当模板，像写笔记一样改，改完保存立即生效，也方便同步与版本管理。

{{todo_list}} {{mission_list}} {{urgent_list}} {{todo_heading}} {{date}} {{date:YYYY年M月D日}} {{weekday}} {{yesterday}} {{tomorrow}} {{title}} {{folder}} {{month_link}} {{cursor}}

功能五 · 每天第一次打开自动进入 可关

三档可选：不自动打开（只创建）／仅新建时打开（只在刚补建出来那一次）／每天首次启动打开（默认）。 跨天补建永远不抢焦点，避免半夜写东西被切走。

设置说明

安装 三步

  1. 把 daily-note-template 文件夹放进 <你的仓库>/.obsidian/plugins/。
  2. 打开 Obsidian → 设置 → 第三方插件；若提示「受限模式」，先关闭。
  3. 点「刷新」，在列表里启用「日记模板 Daily Note Template」。

更新插件时只需替换 main.js / manifest.json / styles.css，然后 Ctrl+R 重载。

常见问题

昨天打勾的任务，今天又出现了？

这是设计如此：待办是「每日固定清单」，勾选只对当天有效，第二天会还原成未勾选。

一次性任务怎么处理？

放进 Mission 或 Urgent mission。两栏规则完全一样：没做完带到下一天，打勾后第二天消失，当天的记录仍然保留。

会不会覆盖我写过的东西？

不会。自动套用只对「空白日记」生效；「用模板重建」是手动命令，并且会先弹窗确认。

为什么旧日记没有月份链接？

功能上线前建的笔记不会自动改动。运行「给已有日记补上月份链接」补齐即可；旧日记在别的文件夹时，把目录填进「额外日记文件夹」。

数据存在哪？会不会联网？

全部在你的仓库里（笔记 + 插件目录下的 data.json），插件不联网、不上传任何内容。
